This repository contains the data and code for the analysis conducted in the scientific publication "Legacy effects of European colonialism on hotspots of biocultural diversity threat" published in the Journal People and Nature.

The repository structure is as follows:


> Data
- this folder contains all data used for the analysis. Raw data is not included if it is available freely from other datasets.
>> 2024-09-03-Dataframes.RData
- This is an R object that contains the dataset necessary to perform all analysis and visualizations.
>> 2024-09-03-Hotspot-Models.RData
- This is an R Object, that contains all models outputs for the analysis.

> Figures
- This folder contains all figures for the manuscript and supplementary material

> Scripts
- This folder contains all R-scripts necessary to replicate the analysis and generate the figures. In a ddition it contains scripts with custom functions that help with visualizing the results.
